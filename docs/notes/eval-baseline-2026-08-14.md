## Как получены эти цифры

Golden-set пересобран `uv run python -m habitus.eval.curate`. Эталон строится
ПРАВИЛАМИ по колонкам БД, а не прогоном поиска: иначе eval измерял бы «возвращает
ли система то, что она возвращает» и всегда показывал бы единицу. Жёсткие условия
запроса (комнаты, бюджет, площадь, «тихо», отсутствие баров) отсекают, гео и
уровень шума — ранжируют. В эталон не попадают объекты дешевле 100 тыс. ₽/м²
(медиана по базе 650 тыс.) — это доли и битый парсинг, а не выгодные предложения.

Пороги шума переведены с абсолютной шкалы (55/65 дБ) на перцентили экспозиции:
слой модельный, у него несколько дискретных значений по классу дороги и средние
65 дБ, поэтому абсолютная шкала отправляла весь город в medium/high и градация
переставала нести информацию (0 объектов `low`). Стало 338 low / 315 medium /
326 high, и запросы «тихо» снова выполнимы.

Путь метрики `rrf+rerank+prox` recall@10:

| состояние | recall@10 |
|---|---|
| устаревший эталон на исправленных данных | 0.21 |
| эталон перекурирован | 0.38 |
| + пороги шума по перцентилям | **0.67** |

Прежние 0.81 сняты на устаревшем эталоне и старых данных — с текущими числами
не сопоставимы.

**Оговорка о том, что меряет метрика.** Релевантность для a01-a10 определена
структурными ограничениями, а proximity-стадия ранжирует по тем же `walk_min_*`.
Варианты с `prox` выигрывают отчасти по построению: таблица показывает, достаёт ли
пайплайн объективно лучшие по условиям объекты, а не качество семантического
канала. Свободную семантику проверяют b04/b05, у которых эталона выдачи нет.

**Открытый вопрос.** На длинных прогонах eval трижды наблюдалось падение бэкенда
Postgres («server process exited with exit code 2» + перезапуск кластера и
WAL-восстановление; данные каждый раз целы). Нагрузка только ретривалом
(15 прогонов всех запросов) не воспроизводит. Подъём `shm_size` до 1 ГБ падения не
устранил. Причина не установлена — при повторении прогона надо включать
`log_statement='all'` ОТДЕЛЬНЫМ вызовом psql: `ALTER SYSTEM` не выполняется внутри
многооператорного `-c` (транзакционный блок) и молча не применяется.
